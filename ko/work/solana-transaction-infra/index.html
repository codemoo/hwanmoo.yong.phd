Rust 기반 솔라나 고빈도 트레이딩 시스템 개발

개발·2025·아키텍처 설계·Rust 핵심 개발·인프라 운영

솔라나의 고빈도 트레이딩은 밀리초 차이로 승부가 갈립니다. 블록은 약 400밀리초마다 마감되므로, 블록 생산자에게 늦게 닿은 트랜잭션은 그 블록에 들어가지 못합니다. 트랜잭션을 블록 생산자까지 나르는 중계 시스템과 그 위에서 거래하는 트레이딩 엔진을 모두 Rust로 만들었습니다.

아키텍처를 설계하고 핵심 구성 요소를 직접 개발했습니다. 사용자와 밸리데이터 사이에 둔 중계기와 프록시는 들어오는 트랜잭션을 하나씩 검사하고 우선순위를 매겨 밀리초 안에 넘깁니다. 트레이딩 엔진은 여러 지역의 중계 서버가 공유한 트랜잭션 데이터를 바탕으로 거래를 번들로 묶어 블록 생산자에게 보냅니다.

모든 단계는 블록 하나의 시간 안에 여유 있게 끝나야 했습니다. 중계기 내부의 데이터 흐름과 네트워크 연결을 다시 짜서 처리 경로에서 대기와 메모리 복사, 버퍼링 지연을 걷어 냈습니다. 여러 밸리데이터로 꾸린 자체 테스트 클러스터에서는 중계기를 거친 블록이 표준 밸리데이터 소프트웨어로 만든 블록보다 수수료를 꾸준히 더 많이 담았습니다.

해외 여러 지역의 전용 서버로 인프라를 직접 구축하고 운영했습니다. 이 시스템은 그 서버들에서 실제 트랜잭션을 처리하며 솔라나 메인넷에서 가동됐습니다.
