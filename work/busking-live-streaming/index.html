Live-streaming app for street musicians

Development·2021–23·iOS/Android app and real-time server

This busking app lets a musician go live from a single phone, and the audience gathers on virtual streets to watch. Viewers take seats, wave light sticks and send emoji or tips while the song is still playing. For that to feel like being there, the video has to arrive in real time and every reaction has to reach the whole audience at once.

Video goes out over a real-time video network, not in the few-second segments of standard HTTP live streaming, so viewers see the show as it happens. Each stage is one channel, with the performer's phone as the broadcaster and every viewer as an audience member who only receives. When the performer switches to sound only, every viewer's screen switches with it at the same moment.

I built the real-time server that carries everything except the video: an API and a WebSocket layer that push every stage update and reaction to everyone watching the moment it happens, and carry chat between viewers. When two performers claim the same free spot or several viewers tap the same seat at once, atomic locks in an in-memory store let exactly one through. Heartbeats from every phone keep each stage's status current, and a weak connection never ends a show that is still live.

On the phone, I built the broadcast start-up that brings a show up in a fixed order: stereo audio tuned for live music, portrait HD video, then a preview and a connection check. The app runs on iOS and Android from one Flutter codebase, so any phone is all a performer needs to reach the whole audience in real time.
